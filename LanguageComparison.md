# Language Comparison Sheet (2025 Edition)

This sheet compares the 7 languages you selected:
- Python  
- TypeScript  
- SQL (PostgreSQL)  
- Rust  
- Go  
- C# (.NET 8)  
- HTML + CSS + JavaScript (Browser Runtime)

---

## 1. What Each Language *Is Best At*

| Language | Primary Strengths | Typical Domains |
|---------|--------------------|-----------------|
| **Python** | Fast prototyping, readable syntax, rich libraries | Data science, scripting, automation, web backends, ML |
| **TypeScript** | Type-safe frontend & backend JS, strong tooling | Web apps, APIs, full-stack apps (Node), hybrid apps |
| **SQL (PostgreSQL)** | Data querying, storage, analytics | Databases, reports, backend persistence |
| **Rust** | High performance & memory safety, zero-cost abstractions | Systems programming, game engines, WASM, embedded |
| **Go** | Concurrency, simple syntax, fast compilation | Cloud services, DevOps tooling, networking, APIs |
| **C# (.NET 8)** | Enterprise-scale systems, Unity game dev, cross-platform | Games (Unity), web APIs, enterprise apps, desktop/mobile |
| **HTML + CSS + JS** | UIs, interactivity, browser apps | Websites, dashboards, PWAs, browser games |

## 2. Difficulty & Learning Curve

| Language | Learning Curve | Reason |
|----------|----------------|--------|
| **Python** | ★☆☆☆☆ (Very Easy) | Simple syntax, forgiving |
| **TypeScript** | ★★☆☆☆ | Adds types to JS, moderate |
| **SQL** | ★★☆☆☆ | Declarative, but thinking in sets takes practice |
| **JavaScript** | ★★☆☆☆ | Easy to start, tricky async & DOM |
| **Go** | ★★★☆☆ | Easy syntax, but you must learn concurrency patterns |
| **C#** | ★★★☆☆ | Large ecosystem, OOP-heavy |
| **Rust** | ★★★★★ (Hardest) | Ownership, lifetimes, strict compiler |

## 3. Paradigms & Typing Model

| Language | Typing | Paradigms |
|----------|--------|-----------|
| **Python** | Dynamic | Multiparadigm: procedural, OOP, functional |
| **TypeScript** | Static (with inference) | Functional + OOP + FP-style patterns |
| **SQL** | Declarative | Set-based, relational |
| **Rust** | Static | Systems-level, functional, concurrent |
| **Go** | Static | Procedural + lightweight concurrency |
| **C#** | Static | OOP, functional, async-first |
| **HTML/CSS/JS** | Mixed (JS dynamic) | Declarative (HTML/CSS), imperative/functional (JS) |

## 6. When to Choose Each Language

### **Choose Python if…**
- You want the simplest syntax.
- You’re doing automation, scripting, AI, data processing.

### **Choose TypeScript if…**
- You’re building any modern web app.
- You want JS flexibility with safety.

### **Choose SQL if…**
- You control, analyze, or explore data.

### **Choose Rust if…**
- You want maximum performance and safety.
- You’re building engines, tools, or embedded apps.

### **Choose Go if…**
- You need high-concurrency services with minimal complexity.

### **Choose C# (.NET 8) if…**
- You work in enterprise, cloud, or Unity game development.

### **Choose HTML + CSS + JS if…**
- You’re building anything that runs in a browser.

## 7. Real-World Example Summary

| Problem | Best Language | Why |
|---------|---------------|------|
| Home automation dashboard | HTML/JS + Python backend | Fast to prototype, easy UI |
| Real-time multiplayer server | Go or Rust | Performance + concurrency |
| Full 3D video game | C# (Unity) or Rust (Bevy/Custom) | Engines + performance |
| Data analysis on sensor logs | Python + SQL | Pandas + Postgres |
| Browser-based hobby game | HTML + CSS + JS | Runs instantly anywhere |
